# Confluence MD Exporter

🌐 Расширение для Google Chrome, которое помогает переносить содержимое между Confluence и Markdown.

## ✨ Возможности

- 📤 Экспорт текущей страницы в Markdown или страницы вместе с дочерними страницами в ZIP-архив.
- 📎 Выгрузка вложений вместе со страницами.
- 📥 Импорт Markdown в открытую страницу Confluence: добавление в конец или замена содержимого с подтверждением.
- 🧩 Преобразование основных элементов разметки, блоков кода, раскрывающихся блоков и PlantUML.

## 🚀 Установка

1. Скачайте проект с GitHub и распакуйте архив.
2. Откройте в Chrome страницу `chrome://extensions/`.
3. Включите **Режим разработчика**.
4. Нажмите **Загрузить распакованное расширение** и выберите папку проекта, в которой находится `manifest.json`.
5. Закрепите **Confluence MD Exporter** на панели браузера через меню расширений.

## 📝 Использование

### Экспорт в Markdown

1. Откройте страницу Confluence, которую хотите экспортировать.
2. Нажмите значок расширения и выберите текущую страницу или страницу с дочерними страницами.
3. При необходимости включите выгрузку вложений и отметьте нужные страницы.
4. Нажмите **Скачать**. Файлы появятся в папке загрузок Chrome.

### Импорт Markdown в Confluence

1. Откройте страницу Confluence, куда нужно импортировать содержимое.
2. В окне расширения выберите файл `.md`.
3. Выберите добавление содержимого в конец страницы или замену. Для замены подтвердите действие.
4. Нажмите **Импортировать в Confluence**.

Для импорта необходимы права на редактирование страницы.
